Comece rápido

  1. Escolha um instrumento no menu lateral.
  2. Adicione notas no Piano roll ou marque passos na bateria.
  3. Pressione Tocar para ouvir e use o Mixer para ajustar o som.
  4. Exporte o projeto JSON para continuar depois ou renderize WAV.

Nota: este é um estúdio web original inspirado em DAWs profissionais, não uma cópia do FL Studio. Os sons sintetizados são básicos e não substituem bibliotecas de samples profissionais.

RECORDING ROOM

Áudio: gravar e exportar

🎙 Gravar microfone

Permita o acesso ao microfone para gravar sua voz ou instrumento externo.

Baixar gravação

A gravação usa o formato compatível com seu navegador (geralmente WebM).

📂 Importar áudio

Carregue MP3, WAV, OGG, M4A ou outro formato suportado pelo navegador.

O arquivo importado pode ser ouvido aqui. Ainda não é automaticamente misturado na renderização WAV.

⬇ Exportar

Exporte o projeto editável ou gere um arquivo WAV do sequenciador, notas e instrumentos básicos.

A exportação WAV é uma renderização básica; áudio importado e gravações não entram automaticamente na mixagem.
